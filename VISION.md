# Vision

Gameroom is a persistent online game den where friends gather to spend time
together. **The gathering comes first; choosing a game is a recurring part of
the visit.**

- **Gather, then choose.** Friends enter a shared room, catch up, browse the games
  together and decide what to play.
- **Get everyone to the table.** Choosing a game gets the selected friends to
  the same table. Gameroom handles routine setup and joining, without copying
  table links or rebuilding the group in each game.
- **Keep the gathering alive.** Games open independently while the room stays
  open. Presence, chat, voice and video continue before, during and between
  games. Switching games keeps the same people and conversation together.
- **Make it feel like a game den.** A cozy room and graphical shelves invite
  browsing. A collection of any size stays easy to explore, with clear,
  accessible controls.

**Our test for progress:** does this make it easier for friends to spend an
evening together, choosing and playing games with less coordination and fewer
interruptions?
