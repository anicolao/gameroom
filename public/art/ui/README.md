# Game menu image

`game-menu.png` is the transparent walnut-and-brass corner menu button used by the
local frame study. Generated with the built-in image_gen tool on 2026-11-25, then
resampled to 128×128 with Sharp for delivery; alpha is preserved. The rendering
and three dots are part of the image, not HTML or CSS artwork. The surrounding
HTML button supplies accessible naming, keyboard interaction and a 44px target.

## Generation prompt

Use case: stylized-concept. Asset type: small rendered UI button sprite for a cozy board-game room. Create one isolated circular dark walnut button, photographed/rendered straight-on, with a very thin aged brass rim and exactly three clear warm ivory/brass circular dots arranged horizontally across its center (ellipsis menu symbol). Restrained tactile 3D material, subtle bevel, soft studio light from upper left. Simple silhouette and strong legibility when displayed at 28 CSS pixels. Front face very dark brown, not green. Center the button tightly in a square canvas with only a small transparent margin; real transparent background, no room, no board, no additional objects, no lettering, no typography, no mockup, no hand, no large drop shadow. Single finished game UI asset.
