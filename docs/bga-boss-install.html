Test BGA Boss

  1. Download BGA Boss and unzip it.
  2. In Chrome, open chrome://extensions, enable Developer mode, choose Load unpacked, and select the unzipped directory containing manifest.json.
  3. Copy its extension ID. Open this Gameroom preview with ?bga=1 (or add &bga=1 to a room invitation). Create a room and invite a friend in a separate browser profile.
  4. Paste the extension ID into the BGA test launcher. Select the players using the existing player checkboxes, then choose Set up Can't Stop on BGA. Approve the request in the extension's own window.
  5. Log in to BGA in the opened tab. Create a realtime Can't Stop table through BGA's own controls and choose its access settings there. BGA's account, Premium and table-access requirements still apply.
  6. Once BGA navigates to /table?table=…, Gameroom shares its address with the selected players automatically. If the room changed meanwhile, return to Gameroom and use Share BGA table with room to retry publication. Your friends get the same table address. If their popups are blocked, they use the Open Can't Stop (BGA) button. They join seats and the host starts play on BGA.

No link copying or extension installation is required for guests. Gameroom and room chat remain open.

Scope of this proof of concept

This version opens BGA and captures the managed tab's table URL. It does not call an undocumented creation endpoint, invite BGA accounts, bypass table-access rules, make a table public, or start a match. Table access and actual seat joining need to be verified with your real BGA accounts. A numeric table address may be insufficient for a private invitation; if BGA requires a separate access token, stop and report it rather than opening public matchmaking.

The adapter is explicitly Can't Stop, BGA game 11. It is a test launcher, separate from the shared catalog; no production catalog entries were modified.

Permissions and recovery

The host approves each request. Only top-level pages on https://gameroom.boardgamescafe.org/ and its numbered PR preview paths may call the bridge. Production and previews share an origin: only test previews you trust. The extension can observe URLs on BGA's canonical and English hosts and stores a small local request journal. It has no cookies, scripting, debugger, broad tabs, Firebase or network-server permissions.

Reloading Gameroom checks the same request. The bridge never creates another BGA tab for an existing request. If a request is interrupted or its tab closes, check your BGA tabs before finishing it and beginning another. An approval window can be reopened from the extension toolbar. If Chrome reuses a managed tab for an unrelated BGA table, that table is a candidate too; inspect it before sharing.

Removing BGA Boss revokes the bridge and removes its local journal. Room history remains in Firestore. The extension ID can change when you load it from a different directory; update it in Gameroom.
